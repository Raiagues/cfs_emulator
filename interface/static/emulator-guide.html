Install the emulator

  1. In Infrastructure select Emulator, choose the board and operating system, and save the image name.
  2. Choose Install dependencies. On a new Docker installation sign out and back in to activate group access.
  3. Choose Install emulator image. Setup tries the registry and builds the project Dockerfile locally if the download fails. The image includes QEMU and the guest OS.
  4. For an offline image archive, use docker load -i /path/to/emulator.tar. Enter its tag under Emulator image and run Install emulator image to prepare the SSH key.
  5. Return to Infrastructure and choose Verify setup. After all checks pass, open the workspace and start the emulator.
