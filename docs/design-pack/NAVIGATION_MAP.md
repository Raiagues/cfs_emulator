## Comparison with the first-run flow

- Welcome, its chapter controls, Skip and Start are absent.
- Free Architecture, Hardware, Code, Ground and Synthetic data visits change the current stop. `journey.js:16`
- Reset hides evidence in one browser and stays on the open route. `journey.js:42`
- Next uses local ordering and a live-boot condition. `journey.js:28`
- Every stop receives a link before its prerequisites are observed. `journey.js:64`
- Board lacks the #board route and the originating journey context. `journey.js:34`
- Opening a target URL saves settings and verifies it. `infrastructure.js:506`
- Target and profile selection share the settings mutation in Setup. `infrastructure.js:220`
- Setup sends individual probes instead of one NDJSON batch. `infrastructure.js:252`
- Entering or refreshing Boot launches the build and run job. `first-boot.js:258`
- Entering Command can open an app or command dialog on Back. `app.js:947`
- Setup actions and Add sensor use the duplicate setup URL. `app.js:509`
- View active flight switches targets and opens Boot. `app.js:512`
- Select board dispatches a click on the toolbar selector. `app.js:1255`
- Viewing Sensor or Test posts the default orbit calculation. `orbit-preview.js:171`
- The label describes a build while the job stops the cFS process. `command-launch.js:17`
- The launch card and toolbar use different names for Run cFS. `command-launch.js:27`
- Setup exposes the old Continue label. `infrastructure.html:46`
- The brand goes directly to the legacy Setup URL and has no Welcome menu. `index.html:23`
- System overview shares the guided route with Round trip. `round-trip-view.js:132`
- Reading first-boot status can start a log job. `interface/server.py:555`
- Sensor start cannot operate on Native or Board. `interface/server.py:149`
- Shipped apps and file mtimes can earn App or Command credit. `interface/backend/journey.py:19`
- Each stop is credited independently of earlier steps. `interface/backend/journey.py:63`
- Disconnecting the ground station loses Event progress. `interface/backend/journey.py:40`
- Connect or Send can issue TO subscriptions on the operator’s behalf. `ground_station/station.py:162`
